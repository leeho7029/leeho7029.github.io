About Me

안녕하세요, Java 기반 웹서비스 운영과 개인 프로젝트를 경험한 개발자 김이호입니다. 저는 기술이 실제 사용자의 불편을 줄이고 업무 흐름을 개선하기 위한 실용적인 도구라고 생각합니다.

실무에서는 T셀파와 우리반 T셀파의 이벤트 페이지 개발, 신규 메뉴 개발, 웹/모바일 결함 수정, T-Talk/T-Call 기능 보완, 크롤링 오류 수정 및 배치 모니터링 업무를 수행했습니다. 운영 환경에서 화면 현상, 소스 흐름, DB 데이터를 함께 확인하며 원인을 분석하고 안정적으로 수정하는 경험을 쌓았습니다.

개인 프로젝트에서는 Spring Boot, React/Next.js, Kotlin, Node.js 등을 활용해 예약·채팅·푸시 알림, 전적 수집·분석 기능을 구현했습니다. 실무에서 부족했던 영역은 프로젝트와 학습을 통해 보완하며, 기존 시스템의 구조를 빠르게 이해하고 필요한 기능을 안정적으로 붙이는 개발자가 되고자 합니다.
